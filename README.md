# Todo App (Flutter + GetX)

A feature-rich Todo application built using Flutter and GetX for state management. This app helps users efficiently manage daily tasks with features such as task creation, calendar-based organization, completion tracking, and user profile management.

---

## Features

### Task Management
- Create, update, and delete tasks
- Mark tasks as completed
- View active and completed tasks separately
- Search functionality for filtering tasks

### Calendar Integration
- Add tasks based on selected dates
- View tasks for each specific date
- Organized date-wise task tracking

### Profile Management
- View user profile details
- Edit profile information
- Change password functionality
- Logout with confirmation dialog

### Authentication
- Login screen with form validation
- Email format validation
- Loading indicator during login process

---

This project uses GetX for:
- State management
